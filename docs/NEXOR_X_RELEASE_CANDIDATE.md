# NEXOR X — Release Candidate

## Versão

0.56.0

## Marco

A Update 56 encerra a fase de construção da arquitetura do NEXOR X.

A partir de `RC_READY`, a arquitetura deve permanecer congelada. Alterações
posteriores devem ocorrer somente quando houver:

- bug real;
- falha de integração;
- risco operacional detectado;
- evidência objetiva de que algum gate precisa ser corrigido.

## O que continua rodando

O sistema permanece em PAPER/TESTNET acumulando:

- Final Validation Campaign;
- evidências de performance;
- trades fechados;
- Profit Factor;
- drawdown;
- estabilidade operacional.

## O que RC_READY não significa

Não significa autorização LIVE.

LIVE permanece bloqueado até que todos os critérios de certificação definidos
sejam satisfeitos e exista uma etapa explícita posterior de liberação.
