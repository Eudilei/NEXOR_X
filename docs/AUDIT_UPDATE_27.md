# Update 27 — Command Center v2

## Objetivo

Trazer para o painel web os módulos que foram adicionados depois da primeira versão
do Command Center.

## Exibe

- estado geral e serviços;
- preço/regime/direção;
- Quant Brain e calibração;
- portfólio PAPER;
- scanner;
- estratégias;
- alocação;
- Recovery Guard;
- Operational Supervisor;
- CQO Certification;
- IA Ollama.

## Segurança

Endpoints administrativos continuam exigindo token.
O token é informado pelo usuário na própria sessão do navegador e não é persistido
pelo painel.

O painel não cria ordens, não altera modo e não habilita LIVE.
